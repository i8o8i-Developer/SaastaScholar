Primary Goal

This Is A Public Marketing Website Only.

Do Not Build The Full Student Dashboard Yet.

The Website Must Explain The Product Clearly, Build Trust, Demonstrate The User Experience, And Convert Students Into Getting Started.

The Architecture And UI Should Be Designed So A Real Student Dashboard Can Be Added Later Without Redesigning The Brand.

Brand Positioning

Position The Product As:

"Everything You Need For Your University Life — In One Place."

Alternative Supporting Message:

"Notes, Assignments, Practicals, Papers, Notifications And Planning — Organized Around Your University, Department, Semester And Section."

The Product Should Feel Like A Combination Of:
